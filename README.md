# About

This repository documents my journey through **30 practical Bioinformatics projects** developed entirely in Python.

Throughout this challenge, I implemented algorithms commonly used in computational biology, progressing from basic DNA sequence manipulation to classical sequence alignment algorithms and phylogenetic tree construction.

Each project focuses on a different concept and builds upon the knowledge acquired in previous days.
